# SOLVA v0.6 — Adversarial Runtime Control Layer

This milestone hardens the existing v0.5 capability contract with an executable decision gate.

Flow: MISSION → TASK → POLICY → PERMISSION → SENTINEL → APPROVAL → TOOL → VERIFY → AUDIT

The layer enforces deny-by-default consequential writes, credential denial, untrusted external content, identity resolution before outreach, evidence integrity, idempotency, and explicit approval for production or binding actions.

This is a controlled hardening milestone, not a production deployment. Live connectors remain separately governed.
