# SOLVA v0.7 — End-to-End Mission Execution

Purpose: unify the existing controlled capabilities into one evidence-first, outcome-verified mission loop.

Core rule:

> No hallucinated fact -> no unsupported decision -> no unverified action -> no claimed outcome without evidence.

Mission flow:

MISSION -> UNDERSTAND -> RESEARCH -> EVIDENCE -> DIAGNOSIS -> CONFIDENCE -> SOLUTION -> EXPECTED_OUTCOME -> QA -> SENTINEL -> EXECUTE -> VERIFY_ACTUAL_OUTCOME -> COMPARE_EXPECTED_ACTUAL -> LEARN -> CLOSE_OR_CONTINUE

Authority remains separate from intelligence. External writes are denied by default. Credentials remain inaccessible to agents. Production changes and binding commitments require approval. Sentinel cannot be bypassed or self-disabled.

This is a development milestone. It is not a production deployment claim.
